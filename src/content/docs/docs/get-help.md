**Check the troubleshooting table first — most error messages are covered there. Otherwise, open an issue or email us.**

- [Troubleshooting](/docs/how-to/troubleshooting/) — what mcpwarp's error messages mean and how to fix them.
- [GitHub issues](https://github.com/mcpwarp/mcpwarp-cli/issues) — file a bug or feature request against the CLI.
- Email [support@mcpwarp.io](mailto:support@mcpwarp.io) — for anything else, including account and billing questions.
